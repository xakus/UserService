# UserService

![UserService Banner](https://img.shields.io/badge/UserService-SpringBoot-blue?style=for-the-badge)

## Описание
**UserService** — это микросервис аутентификации и управления пользователями для современных распределённых систем. Сервис реализует хранение, аутентификацию, кэширование и быстрый доступ к данным пользователя с помощью современных технологий.

## Технологии и архитектура
- **Java 17+** (Spring Boot)
- **Maven** для сборки
- **PostgreSQL** — основная реляционная база данных
- **Redis** — кэширование и хранение сессий пользователей
- **Docker & Docker Compose** — контейнеризация и быстрая развёртка
- **Systemd** — автоматический запуск сервиса на Linux

## Необходимое ПО
Для запуска сервиса необходимы:
- Docker
- Docker Compose
- Java 17+
- Maven
- PostgreSQL
- Redis

## Структура базы данных
Основная сущность:
- **User**: содержит id, имя, email, пароль и другие атрибуты.

**Redis** используется для хранения сессий и токенов пользователей:
- Класс `RedisUser` хранит пару токен + объект пользователя.

## Использование Redis
В проекте реализован сервис `RedisService`, который отвечает за:
- Сохранение токена пользователя и его данных (`saveToken`)
- Получение пользователя по токену (`getToken`)
- Удаление токена (`deleteToken`)
- Очистку старых токенов одного пользователя при входе с нового устройства (`checkOnCollision`)

### Классы для работы с Redis
- `RedisUser` — модель для хранения токена и пользователя
- `RedisService` — сервис для взаимодействия с Redis через Spring Data Redis

## Запуск

### На Linux
1. Убедитесь, что установлены Docker и Docker Compose. Скрипт `start.sh` автоматически установит их при необходимости.
2. Запустите:
   ```bash
   sudo chmod +x start.sh
   sudo ./start.sh
   ```
   Это поднимет все контейнеры и сервис UserService.

### На Windows
1. Установите Docker Desktop и убедитесь, что он запущен.
2. Запустите:
   ```bat
   start.bat
   ```
   Это поднимет все контейнеры и сервис UserService.

## Контейнеризация
В папке `docker-file` находится `docker-compose.yml` с настройками для PostgreSQL, Redis, и самого сервиса UserService.
